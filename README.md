## ✨ Features

- 🖼️ **Square Maker** - Convert any image to perfect 1:1 ratio without cropping or stretching
- 🔄 **Format Converter** - Convert between PNG, JPG, WebP, GIF, and BMP formats
- 🎨 **Smart Backgrounds** - Choose solid colors, transparent, blur extend, or AI-powered smart extend
- ⚡ **Lightning Fast** - All processing happens locally in your browser
- 🔒 **100% Private** - Your images never leave your device
- 📦 **Batch Processing** - Process multiple images at once
- 💾 **Quality Control** - Adjust output quality with lossless options
- 📐 **Custom Dimensions** - Set exact output sizes with linked aspect ratios

## 🛠️ Tools

### Square Maker
Transform any image into a perfect square format - ideal for social media profiles, product photos, and thumbnails.

**Background Options:**
- **Solid Color** - Choose from presets or custom colors
- **Transparent** - Perfect for PNG outputs
- **Blur Extend** - Extends edges with a beautiful blur effect
- **Smart Extend (AI)** - Intelligently extends image edges for seamless results

### Format Converter
Convert images between popular formats with zero quality loss.

**Supported Formats:**
- PNG, JPG, WebP, GIF, BMP, TIFF

## 🚀 Demo

## 📖 Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/itxRishabh/ImgKit.git
   cd ImgKit
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   open index.html
   ```

3. **Start processing images**
   - Drag and drop images or click to browse
   - Adjust settings as needed
   - Download processed images individually or all at once
